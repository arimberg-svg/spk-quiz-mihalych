Почта теста

FormSubmit письма не доставляет. Настройте надёжный канал через Google Apps Script (отправка из вашего Gmail) — 2 минуты.

Шаги

  1. Откройте script.google.com (войдите в Google-аккаунт, связанный с arimberg@gmail.com).
  2. Новый проект → удалите код по умолчанию → вставьте код из файла mail-relay.gs (ниже).
  3. Сохраните → Развернуть → Новое развёртывание → тип Веб-приложение.
  4. Выполнять от имени: Меня. Кто имеет доступ: Все.
  5. Скопируйте URL веб-приложения и вставьте ниже → «Проверить».
  6. Пришлите этот URL в чат Cursor — встрою в тест и выложу на сайт.
