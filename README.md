# Тест СПК — У Михалыча

Интерактивный тест на знание регламентов старшего продавца-консультанта сети **«У Михалыча»**.

## Содержание

- 27 вопросов с вариантами ответа
- 8 открытых вопросов (оценка по ключевым словам + эталон в разборе)
- Темы: рабочий день СПК, обход, контрольные точки, деловое общение, внешний вид, бейджи, пустые крючки, первичка, заказы, сберинкассация, форс-мажоры

## Источники

- Регламент работы СПК
- Инструкция по деловому общению
- Чек-лист дел СПК / рабочий день управляющего
- Инструкция «Сберинкассация»

## Запуск

Откройте `index.html` локально или через GitHub Pages.

## Стек

Статический сайт: HTML + CSS + JS, без сборки.
